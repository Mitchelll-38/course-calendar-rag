# Frontend agent instructions

Before writing or changing any Next.js code, first install the frontend dependencies if needed, then read the relevant documentation in the actual installed `node_modules/next/dist/docs` directory. Do not skip this step or substitute remembered, online, or version-mismatched documentation. Inspect the specific docs for the APIs and conventions you intend to use before editing code.

Keep TypeScript strict and run `npm run check` after changes to TypeScript files. Run `npm run build` when app code is present and build behavior is affected.
